# Bumper Mission Book Presentation

## 🎯 IFAG Bachelor RAC - Jury Presentation

Présentation interactive immersive pour le mission book Bumper - Avenue 83, Var

## 🚀 Comment utiliser la présentation

### Option 1: HTTP Server (Recommandé)
```bash
cd /tmp/bumper-slides
python3 -m http.server 8080
```
Puis ouvrir votre navigateur à: `http://localhost:8080/bumper-presentation.html`

### Option 2: Ouvrir directement
Double-cliquez sur `bumper-presentation.html` pour l'ouvrir dans votre navigateur par défaut.

## 🎮 Navigation

- **Clavier**: Flèches ← → (ou ↑ ↓) pour naviguer entre les slides
- **Souris**: Cliquez sur les flèches navigation ou les points en bas
- **Tactile**: Swipe gauche/droite sur mobile/tablette
- **Progress**: Barre de progression en haut + compteur (1/12)

## 📊 Contenu - 12 Slides

1. **Cover** - Page titre avec logo Bumper
2. **Mission & Contexte** - Présentation de la mission et de l'enseigne
3. **Diagnostic SWOT** - Forces, Faiblesses, Opportunités, Menaces
4. **Clientèle & Personas** - Lucas (étudiant) et Marie (cadre)
5. **Analyse Concurrentielle** - Comparaison Bumper vs concurrents
6. **Espace de Vente Scénarisé** - 4 zones du parcours client
7. **Bumper Lab** - L'animation innovante en détail
8. **Stratégie Réseaux Sociaux** - 4 plateformes avec règle 80/20
9. **Calendrier Éditorial** - Planning hebdomadaire complet
10. **Publications Réseaux Sociaux** - 3 exemples de publications
11. **Objectifs SMART & Bilan** - KPIs et budget Bumper Lab
12. **Conclusion** - Points clés et remerciements
